# Projeto C3 - Roleta de Markov
Projeto da disciplina de Processos Estocásticos e Simulações (C3).


## Tecnologias Utilizadas
* HTML5, CSS3, JavaScript
* Python (API Local e Servidor Web)

## Como executar o projeto localmente
1. Faça o clone deste repositório ou baixe o ZIP.
2. **Aviso importante:** Devido às requisições que o front-end faz para a API Python (fetch) e políticas de segurança de navegadores (CORS), não abra o arquivo roleta-markov.html diretamente com um duplo clique nem utilize o Live Server. O Python fará o papel do servidor.
3. Abra a pasta do projeto em um editor de código, como o VS Code.
4. Abra o terminal integrado na pasta do projeto.
5. Inicie o servidor executando o comando python api_markov_4.py (ou py api_markov_4.py no Windows).
6. O projeto iniciará no terminal. Clique no link gerado ou acesse http://127.0.0.1:8787 no seu navegador.
